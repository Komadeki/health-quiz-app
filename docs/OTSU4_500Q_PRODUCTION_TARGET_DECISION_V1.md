## Decision

The 600-question commercial production target is superseded by a 500-question target, starting from the 305 canonical, source-verified questions on GitHub `main` at `1aa2591cc10093f40a2dc494507452b16efa9d80`.

- 法令: 217

## Operating policy

The target permits a modest reduction in density compared with the superseded 600-question plan. It does not relax any safety or quality gate.

- Prefer the lightest capable authoring and review method.
- Every question remains original, source-bound by source ID/version/pinpoint locator, and subject to semantic-collision checks.
- Permanent IDs remain immutable and are allocated only through the existing acceptance and integration path.
- Existing validation, distinct AI-author/reviewer/Director identities, source verification, and durable GitHub evidence remain required.
- The target is not a quota: record a coverage-limit decision instead of creating filler or unsupported variants.
