# Single unlock fixture

This temporary Phase 2E reference app proves that an independent Flutter shell
can consume `quiz_engine`, an explicit-ID qualification bank, and the
single-full-unlock entitlement flow without importing health app code.

It is a technical fixture, not a production qualification app, and must not be
submitted to App Store Connect. Production qualification structure and UX are
separate work. Final monorepo placement is deferred to Phase 2F.
