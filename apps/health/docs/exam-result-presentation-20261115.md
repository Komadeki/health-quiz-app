# 解答・得点表示の改善

ブランチ: feature/health-result-presentation。審査提出済み1.2.0（106）とは別の次期更新候補。版番号、公開設定、課金、問題データ、採点ロジック、成績の保存形式は変更していない。

## 表示

- 得点を大きく表示し、正答率バー・正答数を添える。100点換算と四捨五入、未回答は不正解として採点することを明記。
- 正解・回答したが不正解・未回答の件数を分け、アイコンと文字で表示。未回答を不正解件数と重複表示しない。
- 復習ボタンを上部へ移動。形式別は数値とバーで、単元別は開閉できる一覧で確認。
- 自分の回答と正解を背景の異なる欄で比較。狭い画面では縦、広い画面では横に並べ、解説に見出しを付ける。
- 間違い・未回答のみの表示切替。元の問題番号を維持し、全問正解なら対象がない旨を説明する。絞り込みで得点や保存データを変えない。
