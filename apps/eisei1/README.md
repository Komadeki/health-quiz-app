# 第一種衛生管理者

第一種衛生管理者試験向けの Flutter アプリです。共通の学習、進捗、弱点復習、
模試、根拠表示、買い切り解放を `qualification_app` と `quiz_engine` から利用し、
資格固有の実行基盤は増やしません。

- 400問（無料30問、解放後400問）
- 公式配分の模擬試験: 44問・180分・10/10/7/7/10
- 合格目安: 総合60%以上かつ各分野40%以上
- 問題の安定ID、出典、coverage は `question_banks/eisei1` に保持

本番のストア商品登録、公開用サポートページ、有資格者による最終確認は、
配布前の別ゲートです。アプリ設定と問題バンク資産は `app.yaml` から生成します。
